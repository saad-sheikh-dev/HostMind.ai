HostMind is an autonomous, event-driven multi-agent retail orchestration engine designed for large-scale supermarkets (D-Mart style).

Led by a central HOST decision core, specialized sub-agents (Agent_Shelf, Agent_Expiry, Agent_Billing, Agent_Cleaning) operate in parallel to prevent stock-outs, execute real-time dynamic pricing markdowns on perishable items, and audit store facilities without human intervention. Built with Python, Streamlit, and Pydantic, powered by Gemma-driven agent summarization.
